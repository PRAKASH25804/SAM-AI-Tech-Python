# Task 3 — Python Text Analyzer

A clean desktop application that analyzes text files and reports counts, frequency, and sentence structure.

## Features

- Count words
- Count characters
- Most frequent words
- Sentence count
- File upload via GUI
- File not found handling and validation

## Requirements

- Python 3.9+
- Tkinter (standard library)

## Install

```bash
python -m pip install --upgrade pip
```

## Run

```bash
python main.py
```

## Usage

1. Click "Open File" and select a `.txt` file.
2. Click "Analyze Text".
3. Review the results in the display area.
