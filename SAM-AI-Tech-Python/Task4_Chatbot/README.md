# Task 4 — Python Chatbot

A friendly Python chatbot with greeting support, small talk, time responses, exit handling, and learning capabilities.

## Features

- Greetings
- Questions
- Time response
- Small talk
- Exit command
- Learn new responses and persist them locally

## Requirements

- Python 3.8+

## Run

```bash
python main.py
```

## Usage

- Type a greeting such as "hello" or "hi"
- Ask "what is your name" or "what time is it"
- Teach the bot a new response by typing a message containing "learn"
- Type "exit" or "quit" to stop the application

## Notes

The chatbot stores learned phrases in `chat_memory.json` so it can remember responses between sessions.
