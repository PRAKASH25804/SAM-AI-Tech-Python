# Task 1 — Modern Python Calculator

A polished dark-themed calculator built with Tkinter. The app supports advanced arithmetic operations, history tracking, and robust error handling.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Square root
- Calculation history with easy review
- Responsive dark GUI
- Error handling for invalid input and division by zero

## Requirements

- Python 3.9+
- Tkinter (standard with most Python installations)

## Install

```bash
python -m pip install --upgrade pip
```

## Run

```bash
python main.py
```

## Notes

The calculator uses a dark modern UI with a responsive layout and history panel. Expressions are evaluated safely using a restricted namespace, and square root is available directly from the button panel.
